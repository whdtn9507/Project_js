# MACHAW Manager

치지직 방송의 채팅과 신청곡을 관리하는 로컬 대시보드입니다. 시청자가 채팅으로 곡을 신청하면, 관리자가 재생할 YouTube 영상을 선택해 승인합니다. 현재 영상이 끝나면 다음 승인곡이 자동으로 재생됩니다.

## 주요 기능

- 치지직 공식 API를 통한 실시간 채팅 수신
- 채팅 명령으로 신청곡 접수 및 관리자 승인·거절
- 곡 제목과 아티스트로 YouTube 검색
- 승인곡 자동 재생 및 다음 곡으로 바로 넘기기
- 실제 방송 연결 없이 가상 채팅으로 신청곡 테스트

## 신청곡 사용법

치지직 채팅창에 아래처럼 입력합니다.

```text
!신청곡 그럼에도 우리의 이름은 달담
```

공백으로 구분하면 마지막 단어가 아티스트입니다. 아티스트 이름에 공백이 있으면 따옴표나 `|`를 사용합니다.

```text
!신청곡 Super Shy "New Jeans"
!신청곡 Super Shy | New Jeans
```

관리자는 승인 대기 목록에서 **YouTube 검색**을 눌러 영상을 찾고, **승인**할 때 영상 링크를 입력합니다. YouTube 플레이어의 시작 링크를 비워 두고 **재생 시작**을 누르면 링크가 지정된 첫 승인곡부터 재생합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```powershell
npm ci
npm run dev
```

브라우저에서 [http://127.0.0.1:3000](http://127.0.0.1:3000)을 엽니다.

실제 치지직 채팅을 받으려면 `.env.example`을 `.env`로 복사하고, 개발자 센터에서 발급받은 `CHZZK_CLIENT_ID`와 `CHZZK_CLIENT_SECRET`을 입력합니다. 앱에는 **채팅 메시지 조회** 권한이 필요하며, 로그인 리디렉션 URL은 `.env`의 `CHZZK_REDIRECT_URI`와 일치해야 합니다. 설정 후 대시보드에서 **치지직 로그인**을 누릅니다. `.env`는 Git에 올리지 않습니다.

## 운영 참고

- 재생은 대시보드에 내장된 YouTube 플레이어에서 이루어집니다.
- 채팅과 신청 목록은 서버 메모리에 저장되며, 서버를 재시작하면 초기화됩니다.
- 이 프로젝트는 로컬에서 운영하는 관리자 도구입니다.
