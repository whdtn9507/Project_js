# MACHAW Manager

마차우 방송의 치지직 채팅과 신청곡을 관리하는 로컬 대시보드입니다. 신청곡에 YouTube 링크를 붙여 승인하면, 현재 곡이 끝난 뒤 다음 승인곡이 재생됩니다.

## Windows에서 실행하기

처음 한 번만 Node.js 22 이상을 설치하고 프로젝트 폴더에서 `npm ci`를 실행합니다.

이후에는 프로젝트 폴더의 [start-machaw.bat](start-machaw.bat)를 더블클릭하면 서버가 시작되고 기본 브라우저에서 대시보드가 열립니다. 바탕화면에서 쓰려면 실행기의 바로가기를 만들고 **마차우 방송 운영실**로 이름을 지정하세요. 방송이 끝나면 **MACHAW Manager Server** 창에서 `Ctrl+C`를 눌러 종료합니다.

개발할 때는 `npm run dev`를 사용할 수 있습니다. 기본 주소는 [http://127.0.0.1:3000](http://127.0.0.1:3000)입니다.

## 치지직 연결

1. `.env.example`을 `.env`로 복사하고 개발자 센터에서 발급한 `CHZZK_CLIENT_ID`와 `CHZZK_CLIENT_SECRET`을 입력합니다.
2. 치지직 앱에 **채팅 메시지 조회** 권한을 설정하고, 등록한 로그인 리디렉션 URL과 `CHZZK_REDIRECT_URI`를 일치시킵니다.
3. 대시보드에서 **치지직 로그인**을 누르고 **채팅 수신 중**이 표시되는지 확인합니다. 인증 정보가 들어 있는 `.env`는 Git에 올리지 않습니다.

## 신청곡 운영

```text
!신청곡 그럼에도 우리의 이름은 달담
!신청곡 Super Shy "New Jeans"
!신청곡 Super Shy | New Jeans
```

공백으로만 구분하면 마지막 단어를 아티스트로 읽습니다. 아티스트 이름에 공백이 있으면 따옴표로 묶거나 `|`로 구분하세요.

1. 신청곡 옆 **YouTube 검색**으로 원하는 영상을 찾습니다.
2. **승인**을 눌러 행 안에서 링크를 입력하고 **승인 확정**을 누릅니다. 대기열에서 빼려면 **승인 취소**를 누릅니다.
3. 대시보드의 **재생 시작**을 누릅니다. 시작 링크를 비워 두면 첫 승인곡부터 재생합니다. 현재 곡이 끝나면 다음 승인곡으로 넘어가며, **다음 승인곡** 버튼으로 바로 넘길 수도 있습니다.

## 방송 운영과 연습 모드

- 기본값은 방송 운영 모드입니다. 승인 대기곡과 재생 대기곡은 로컬 `data/requests.json`에 저장되어 서버 재시작 후 복원됩니다. 채팅과 재생 중인 곡은 복원되지 않습니다.
- 가상 채팅으로 연습하려면 `.env`에 `MACHAW_MODE=demo`를 설정한 뒤 서버를 재시작합니다. 방송으로 돌아가려면 `MACHAW_MODE=live`로 바꾸거나 해당 줄을 지웁니다.
